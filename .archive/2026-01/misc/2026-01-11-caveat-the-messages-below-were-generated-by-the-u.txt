> this is my search results What a Skill Must Look Like
A skill is always a folder under ~/.claude/skills/ (or project 
.claude/skills/).
​

That folder must contain a SKILL.md file at its root. This is the only 
required file and is what actually defines the skill.
​

SKILL.md starts with YAML frontmatter (---) containing at least name and 
description, then the instructions/body.
​

So the minimal valid structure is:

bash
~/.claude/skills/
└── handoff/
    └── SKILL.md
Your “simple skill = single .md file directly under ~/.claude/skills/” is 
not correct; even simple skills are a folder containing SKILL.md, not 
simple-skill.md at the top level.
​

Optional Extra Files
Within the skill folder, you can add supporting markdown and scripts, but 
they are not special by name alone.
​

Valid pattern:

bash
~/.claude/skills/
└── handoff/
    ├── SKILL.md           # required: overview, metadata, main workflow
    ├── reference.md       # optional: extra docs, linked from SKILL.md
    ├── examples.md        # optional: examples, linked from SKILL.md
    └── scripts/           # optional: helper scripts
        └── validate-docs.sh
Claude discovers these via links or references inside SKILL.md; there is no 
special commands/ or hooks/ convention inside a skill folder.
​

Scripts must be executable (e.g. chmod +x scripts/*.sh).
​

Your proposal with:

bash
handoff/
  ├── README.md
  ├── commands/
  ├── hooks/
  └── scripts/
mixes plugin-style layout (commands/, .claude-plugin/) with skill layout, 
which are different systems.
​

Where commands/, hooks/, .claude-plugin/ Actually Belong
commands/, agents/, hooks/, .claude-plugin/ (with plugin.json) are part of a
 plugin directory, not a single skill.
​

In a plugin, skills live in skills/<skill-name>/SKILL.md under the plugin 
root.
​

Example plugin:

bash
enterprise-plugin/
├── .claude-plugin/
│   └── plugin.json
├── commands/
│   ├── deploy.md
│   └── test.md
├── agents/
│   ├── reviewer.md
│   └── tester.md
├── skills/
│   └── handoff/
│       └── SKILL.md
├── hooks/
│   └── hooks.json
└── scripts/
    └── validate.sh
So .claude-plugin/ and commands/ should not be inside 
~/.claude/skills/handoff/ if you are just creating a personal skill.
