# Dashboard Overview

## Purpose
The Documents Dashboard is your main workspace for managing and organizing all documents in the Expert Note system. As an Organization Owner or Admin, this is where you'll access, search, and manage documents across your organization.

## Key Components

### 1. Navigation Menu (Top Left)
The main navigation bar allows you to move between different sections of the application:
- **Expert Note** logo/link - Returns to the dashboard
- **Knowledge Base** - Access extracted knowledge entries
- **Prompts** - Manage extraction guides and prompts
- **Settings** - Access organization and system settings (Admin only)

**Pro Tip:** Use the keyboard shortcut to quickly navigate between sections.

### 2. New Document Button (Top Right)
The blue "+ New Document" button is your primary entry point for document creation. Clicking this button takes you to the document creation page where you can:
- Create a blank document and type content directly
- Upload PDF, DOCX, TXT, or MD files
- Add document metadata before saving

### 3. Search Documents (Left Filter Area)
This text field allows you to search through all documents by content, title, or metadata. The search operates in real-time as you type, filtering the document list below.

**Search Tips:**
- Search is case-insensitive
- Searches through document titles and content
- Results update instantly as you type

### 4. Status Filter (Middle Filter Area)
This dropdown allows you to filter documents by their current status:
- **All Status** - Show all documents regardless of state
- **Draft** - Documents not yet fully annotated
- **In Progress** - Documents with some annotations
- **Completed** - Documents with all required annotations

### 5. Tag Filter (Right Filter Area)
Use this dropdown to filter documents by assigned tags. You can:
- Select multiple tags to narrow results
- Filter documents by topic, project, or category
- Quickly find related documents across projects

**Organization:** Tags are system-wide and can be managed in Settings > Tag Management.

### 6. Statistics Cards (Bottom)
Three key metrics give you an overview of your annotation activity:

**Total Documents:** Shows the complete count of documents in your organization (including those created by others in shared contexts).

**Annotated:** Displays how many documents have at least one annotation across your organization.

**Total Annotations:** Shows the cumulative count of all macro, meso, and micro annotations made across all documents.

## Workflow

### Accessing a Document
1. Search or filter to find your target document
2. Click on the document row in the list
3. The document editor opens in a new section

### Creating Your First Document
1. Click "+ New Document" button
2. Choose "Single Document" tab
3. Enter a document title
4. (Optional) Add tags from the dropdown
5. (Optional) Upload a file (PDF, DOCX, TXT, MD)
6. (Optional) Paste or type markdown content
7. Click "Create Document" to save

### Organizing Documents
- Use **Status** filter to focus on documents needing work
- Use **Tag** filter to group related documents by project or topic
- Use the **Search** field to find documents by keyword

## Permissions

**Organization Owners:** Can see documents created by organization members and documents shared with the organization. Delete and edit permissions depend on document creator.

**Admins:** Full visibility across the system.

## Tips for Organization Owners

1. **Establish a Tagging System** - Work with your team to define a consistent tag structure
2. **Regular Status Updates** - Encourage team members to update document status as they progress
3. **Use Filters for Workflow** - Create focused views by filtering on status or tags
4. **Monitor Statistics** - Use the stats cards to track team annotation activity
