# Creating a New Document

## Overview
The Create New Document page provides multiple ways to add content to the Expert Note system. Whether you're working with existing files or creating fresh content, this page guides you through the process.

## Page Components

### 1. Create Method Tabs
Two tabs let you choose how to create your document:

**Single Document Tab (Default):**
- Create one document at a time
- Fill in all metadata before saving
- Ideal for manual document creation or small uploads

**Bulk Upload Tab:**
- Upload multiple documents at once
- Batch import from your file system
- More efficient for handling many files

### 2. Document Title Field (Required)
Enter the title or name for your document:
- **Required field** - You must provide a title
- Used as the document's primary identifier
- Appears in search results and document lists
- Can be edited later after creation

**Title Suggestions:**
- Use descriptive names: "Q1 2024 Earnings Report"
- Include project codes if applicable: "[PROJ-101] Market Analysis"
- Avoid generic names like "Document 1"

### 3. Tags Field (Optional)
Add tags to categorize and organize your document:
- Click the field to see available tags
- Type to create new tags on-the-fly
- Select multiple tags by clicking each one
- Remove tags by clicking the X next to the tag
- Tags help with searching and filtering later

**Tag Organization Tips:**
- Establish a consistent naming convention with your team
- Use tags for: Project names, Document types, Status indicators
- Examples: "Q1-2024", "Reports", "Internal-Review"

### 4. File Upload Area (Optional)
Upload documents directly from your file system:

**Supported Formats:**
- **PDF (.pdf)** - Best for scanned documents
- **Word (.docx)** - Microsoft Word documents
- **Text (.txt)** - Plain text files
- **Markdown (.md)** - Markdown-formatted content

**How to Upload:**
1. Click anywhere in the dashed box area
2. Select a file from your file system dialog
3. The file will be processed and converted to markdown
4. Content will populate the Content field below

**Important Notes:**
- File will be automatically converted to markdown format
- You can review and edit the converted content before saving
- Large PDFs may take a moment to process
- The original file is not stored; only the converted content

### 5. Content Field (Optional)
Type or paste markdown content directly:

**When to Use:**
- Pasting text from other sources
- Creating documents from scratch
- Editing content before saving
- Adding markdown-formatted content

**Markdown Support:**
- Headings: `# Heading 1`, `## Heading 2`, etc.
- Bold: `**text**`
- Italic: `*text*`
- Lists: `- item` or `1. numbered`
- Code blocks: ` ``` code ``` `
- Links: `[text](url)`

**Character Counter:** Shows how many characters are in your content.

## Creating a Document: Step-by-Step

### Method 1: Create from Scratch
1. Click "+ New Document" on the dashboard
2. Enter a descriptive **Document Title**
3. (Optional) Add **Tags** to categorize it
4. Type or paste content into the **Content field**
5. Click **Create Document** button
6. Document opens in editor

### Method 2: Upload an Existing File
1. Click "+ New Document" on the dashboard
2. Enter a descriptive **Document Title**
3. (Optional) Add **Tags**
4. Click in the **File Upload Area** or drag-and-drop a file (PDF, DOCX, TXT, or MD)
5. System converts file to markdown automatically
6. Review the converted content in the **Content field**
7. Make any necessary edits or adjustments
8. Click **Create Document** button
9. Document opens in editor ready for annotation

### Method 3: Bulk Upload Multiple Files
1. Click "+ New Document"
2. Click the **"Bulk Upload"** tab
3. Select multiple files from your file system
4. Each file becomes a separate document with auto-generated titles
5. Confirm the upload
6. Documents are created and ready for annotation

## What Happens After Clicking "Create Document"

1. **Validation** - System checks that required fields (title) are filled
2. **File Processing** - If a file was uploaded, it's converted to markdown
3. **Document Creation** - A new document record is created in the system
4. **Editor Opens** - You're taken directly to the document editor
5. **Ready for Annotation** - Begin adding macro/meso/micro annotations

## Editing Before Creation

Make sure all information is correct before submitting:
- **Title**: Can be changed in the editor later, but title here prevents confusion
- **Tags**: Can be modified in the editor's sidebar
- **Content**: Review converted file content for accuracy before saving

---

## Common Issues

**"File upload failed"**
- Check that file is one of the supported formats
- Try a smaller file to test the system
- Ensure file isn't corrupted

**"Title is required"**
- Document title is mandatory
- Provide a descriptive name for your document

**"Content looks incorrect after upload"**
- Complex PDFs may convert imperfectly
- Edit content in the editor after creation
- Verify formatting is preserved as needed
