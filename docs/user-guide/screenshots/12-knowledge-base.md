# Knowledge Base View

The Knowledge Base section allows members to browse, search, and filter through captured knowledge entries extracted from annotated documents.

## Overview

**Location:** Knowledge Base tab in main navigation

The Knowledge Base displays all knowledge entries that have been extracted from your annotated documents. This is where you organize and manage your captured knowledge.

## Key Components

### 1. Search Box
**Location:** Left panel, under "Search" heading

Allows you to search through knowledge entries by content. Type keywords to filter the knowledge base in real-time. The search looks through:
- Knowledge entry text/content
- Tags and metadata
- Associated documents

**Usage:**
- Click in the search box
- Type keywords or phrases
- Results update automatically as you type
- Clear the search to see all entries again

### 2. Tag Filter
**Location:** Center panel, under "Tags" heading

Narrows down the knowledge entries displayed based on selected tags. Shows a dropdown/input field to filter by tags.

**Usage:**
- Click the "Filter by tags..." field
- Type or select tags you want to filter by
- Multiple tags can be selected (shows as OR logic)
- Only entries with matching tags will be displayed
- Clear the filter to show all entries

### 3. Statistics Panel
**Location:** Right panel, under "Statistics" heading

Displays key metrics about your knowledge base:
- **Entries count:** Total number of knowledge entries captured
- **Annotations count:** Total number of annotations made across all entries

These statistics help you understand the size and scope of your captured knowledge.

### 4. Table/Card Toggle
**Location:** Top right, above the knowledge list

Switch between viewing your knowledge entries in two different layouts:

- **Table View** (default): Displays entries in a structured table format with columns for title, tags, created date, and actions
- **Card View:** Displays entries as individual cards in a grid layout, useful for visual browsing

**Usage:**
- Click "Table" to switch to table view
- Click "Card" to switch to card view
- Your preference is saved for future sessions

## Workflow Example

### Searching and Filtering Knowledge

1. Navigate to the **Knowledge Base** tab from the main navigation
2. Enter search terms in the **Search box** (e.g., "customer feedback")
3. Use the **Tag Filter** to narrow results (e.g., select "important" tag)
4. Review the **Statistics** to see how many relevant entries match your criteria
5. Click on an entry to view full details and annotations
6. Switch between **Table** and **Card** views to find the layout that works best for you

### Empty State

When you first start using the Knowledge Base, you'll see a message: "No knowledge entries yet. Start by annotating documents!"

This means you haven't captured any knowledge entries yet. To populate your Knowledge Base:
1. Navigate to the **Documents** section
2. Upload or create a document
3. Add annotations using the highlighting tool
4. Save the annotations - they'll automatically appear in your Knowledge Base

## Related Features

- **Annotations:** Each knowledge entry is created from an annotation in a document
- **Tags:** Use tags to organize and categorize your knowledge
- **Documents:** Original documents from which knowledge was extracted
- **Export:** Download knowledge entries for use in other applications

## Tips and Best Practices

- Use consistent tagging schemes to make filtering more effective
- Search for keywords you frequently look up to discover gaps in your knowledge base
- Regularly review your statistics to understand knowledge capture patterns
- Combine search and tag filters for more precise results
- Use Card view for visual scanning, Table view for detailed review
