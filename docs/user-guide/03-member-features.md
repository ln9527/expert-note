# Organization Member Features

As an organization member, you have access to content shared by your organization's owners and can collaborate on documents when editing is enabled.

---

## Your Role as a Member

Organization members can:
- View documents, knowledge entries, and prompts shared by organization owners
- Edit shared content when the owner has enabled edit permissions
- Create and manage your own tags for organizing content
- Update your profile and security settings

---

## Viewing Shared Documents

### Accessing Documents

1. Go to the **Documents** page from the main navigation
2. Shared documents from your organization appear in your document list
3. Each document shows:
   - Title and tags
   - Annotation counts (MACRO, MESO, MICRO)
   - The creator's name
   - Last updated date

### Opening a Document

Click on any document in the list to open it in the document viewer. You can:
- Read the full content with all annotations
- See highlighted annotations at each level
- Navigate between annotation markers

---

## Editing Shared Documents

### When Editing Is Enabled

If the document owner has enabled edit permissions, you can:

1. Click on the document to open the editor
2. Use the annotation toolbar to add annotations:
   - **MACRO** (Cmd+1): High-level themes and main arguments
   - **MESO** (Cmd+2): Supporting ideas and evidence
   - **MICRO** (Cmd+3): Specific details and quotes
3. Select text and click an annotation level to create a new annotation
4. Changes are saved automatically

### When Editing Is Disabled

If the document is view-only:
- You can read the document and all its annotations
- The editor will be in read-only mode
- You cannot add or modify annotations

---

## Viewing Knowledge Entries

### Accessing Knowledge

1. Go to the **Knowledge Base** page
2. Shared knowledge entries appear in your list
3. Use the search bar to find specific entries
4. Filter by tags to narrow your results

### Working with Knowledge Entries

Click on any entry to view:
- Background context
- All extracted annotations organized by level
- Source document reference (if available)
- Associated tags

When editing is enabled by the owner, you can modify the content and annotations.

---

## Viewing Generation Guides (Prompts)

### Accessing Prompts

1. Go to the **Prompts** page
2. Shared prompts from your organization are visible in the list
3. Search by title or filter by tags

### Using Prompts

You can:
- View prompt content and configuration
- See version history
- Use shared prompts as templates for AI generation

When editing is enabled, you can modify the prompt content.

---

## Managing Your Tags

You can create and manage your own tags for organizing content:

1. Go to **Settings > Tags**
2. Create new tags with custom names and colors
3. Delete tags you created (tags created by others cannot be deleted)
4. Tags you create are available when you have permission to edit documents

---

## Account Settings

### Updating Your Profile

1. Go to **Settings > Account**
2. Update your **Display Name** - this appears throughout the application
3. Click **Save Changes** to apply

Note: Your username cannot be changed after account creation.

### Changing Your Password

1. Go to **Settings > Account**
2. Scroll to the **Change Password** section
3. Enter your current password
4. Enter and confirm your new password (minimum 8 characters)
5. Click **Change Password**
